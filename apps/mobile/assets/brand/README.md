# Logos TraeLo (Expo)

Cuando lleguen los logos, coloca aquí:

- `logo.png` / `logo.svg` — marca principal
- `icon.png` — ícono de app (1024×1024)
- `splash-icon.png` — marca para la pantalla de arranque

La UI usa el wordmark tipográfico **TraeLo** hasta integrar estos archivos en `app.json` y el splash.
